still turn out wrong later; a verdict can be right by luck and unjustified.

## Score

- 1.0 = the verdict follows from the inputs and checks, and no reasonable
  alternative verdict fits the same evidence.
- 0.5 = the verdict is defensible, but a reasonable alternative fits the
  evidence equally well, or the inputs are too thin to separate them.
- 0.0 = the verdict does not follow: a check contradicts it, a required
  input is absent, or the inputs point to a different verdict.

Use intermediate values only when you can say which part of the evidence
moved you off a whole point.

## Output

Reply with ONE JSON object and nothing else:

{"score": <number 0..1>, "explanation": "<two sentences at most>", "evidence": ["<each check id or input field your score rests on, e.g. check:four_state or input:issue.body>"]}

`evidence` must name at least one check id or input field. A score with no
evidence is discarded.
